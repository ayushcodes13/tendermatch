# Official tender document retrieval

P4.1 adds bounded retrieval for document URLs explicitly supplied by scrapers. The pipeline considers only `high_signal` and `explore` tenders that have `document_links`, and limits work to 10 candidates and two documents per candidate per run. It does not crawl pages or guess URLs. Retrieval is opt-in: set `TENDERMATCH_DOCUMENT_HOSTS` to a comma-separated exact host allowlist and `TENDERMATCH_DOCUMENT_DIR` to protected persistent storage after checking each source's access conditions. If either setting is absent, the pipeline does no document retrieval. CPPP and GeM are not allowlisted by this change.

The fetcher rejects non-HTTPS URLs, embedded credentials, non-allowlisted hosts, non-public DNS results, redirects, non-PDF content types, invalid PDF signatures, and files larger than the configured limit (20 MiB by default). Network connect/read timeouts are bounded. It uses no cookies, authentication, CAPTCHA interaction, or retry loop. Successful files are written atomically beneath the configured storage directory, named by SHA-256 content fingerprint, and set to owner-only file permissions. The SQLite `tender_documents` table appends retrieval observations, including original source URL, fingerprint, path, status, size, type, timestamp, and coarse error type. A newly observed file version does not overwrite an older version.

SQLite stores metadata and a local path, not the document bytes. The operator must place the storage directory on protected persistent storage, apply suitable backup/retention controls, and protect document contents. Retrieval errors intentionally omit exception messages and response bodies. `unsupported`, `rejected`, `blocked`, and `unavailable` outcomes are retained for review.

## Portal access review (2026-10-22)

- The [CPPP portal policies](https://eprocure.gov.in/cppp/disclaimer/) state that tender documents are owned and maintained by the issuing departments and that reproducing portal material may require permission from the relevant department. The portal describes dissemination and access as its purpose, but that is not blanket permission to retain or redistribute every linked document. Keep CPPP document hosts disabled until the applicable department's conditions are reviewed.
- GeM's official [Terms of Use](https://gem.gov.in/termsConditions) could not be retrieved through the available research connector during this review. No GeM download host is enabled. Recheck the live terms and any bid-specific conditions before enabling retrieval.
- Institutional tender pages such as [IISc All Tenders](https://www.iisc.ac.in/all-tenders/) and [IIT Goa Tenders](https://iitgoa.ac.in/tenders/) publish tender notices and linked documents. Their existence does not by itself establish permission for automated retention or redistribution. Review the institution's applicable website/tender terms for each host before enabling it.

This is an engineering access safeguard, not a legal determination. Operators should use only explicitly linked public documents and must not bypass authentication, CAPTCHA, rate limits, access controls, or portal protections. GitHub Actions currently uses ephemeral runner storage and its DB cache is not guaranteed durable; configure a persistent protected mount before setting the document directory, otherwise downloaded originals may not survive a run.
