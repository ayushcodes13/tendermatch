# Tender PDF text extraction

P4.2 reads native text from downloaded PDFs using pypdf. It never invokes OCR. Image-only documents return `needs_ocr`; encrypted files return `needs_review`; invalid files return `invalid`; inaccessible files and page parsing failures are recorded with coarse error types. Documents larger than 20 MiB are rejected before parsing. Extraction is limited to the first 100 pages and 100,000 characters per page, and pypdf's indirect-object recovery is bounded.

The current deterministic extractor only emits fields explicitly labeled in the document: equipment type, technical specifications, mandatory and optional requirements, quantity, delivery requirements, eligibility requirements, and closing date. It does not infer an unlabeled value, resolve conflicting requirements, determine legal eligibility, or treat document text as instructions. Every emitted value carries the exact extracted line, one-based page number, and original source URL. Unlabeled prose remains available only in the original source document and is not represented as a verified requirement.

Each extraction attempt is appended to `document_extractions` with the document content fingerprint, source URL, status, evidence JSON, and timestamp. Old extraction records remain available when a PDF changes. CI uses synthetic PDFs created in tests; no live tender documents were downloaded. Native text extraction and line-label rules need evaluation against permitted, representative tender PDFs before the output is treated as operationally complete. Scanned pages remain unsupported until a separate OCR workflow is justified and tested.

The PDF parsing library documents that complex compressed content can consume substantial memory and that text extraction quality varies by PDF generator. The 20 MiB file, page-count, and text-character limits reduce routine exposure but do not provide process-level memory isolation against a malicious decompression bomb. Only process trusted, public documents from reviewed hosts; a separate sandboxed worker remains a production hardening item.
